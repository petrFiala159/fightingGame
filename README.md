# Malfini Sklad Arena – kompletní projekt

## Co je uvnitř
- kompletní React + Vite projekt
- rozdělené komponenty
- assets s portréty a pozadím
- herní logika, audio a utility soubory

## Spuštění
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Struktura
- `src/App.jsx` – hlavní hra
- `src/components` – UI komponenty
- `src/game` – constants, utils, audio
- `src/data/fighters.js` – data bojovníků
- `src/assets` – obrázky postav a arény
